# ETH Own Movement Analyser

Приложение для анализа **собственных движений цены фьючерса ETHUSDT** —
движений ETH, очищенных от влияния цены BTCUSDT.
Биржа-источник данных: **BingX** (фьючерсный рынок, публичные рыночные данные,
API-ключи не требуются).

## Постановка задачи

1. Определить собственные движения цены фьючерса ETHUSDT, исключив влияние
   цены BTCUSDT. Методика и параметры описаны ниже.
2. Программа на Python 3.11 в реальном времени следит за ценой фьючерса
   ETHUSDT, методом из части 1 определяет собственные движения ETH и
   **при изменении цены на 1% за последние 60 минут выводит сообщение
   в консоль**. Программа работает постоянно.

## Методика (часть 1)

### Идея

ETH почти всегда движется вместе с BTC: если BTC за минуту вырос на 1%,
ETH в среднем вырастет примерно на 1,2–1,5% — «рыночная» часть его движения.
**Собственным движением** ETH считаем то, что остаётся после вычитания
рыночной части.

### Бета-модель

Связь ETH и BTC моделируем через коэффициент **β (бета)**:

    собственное_движение_ETH = реальное_движение_ETH − β × движение_BTC

где β — чувствительность ETH к BTC, оценённая по историческим данным
(регрессия доходностей ETH на доходности BTC, без свободного члена):

    β = Cov(r_ETH, r_BTC) / Var(r_BTC)

### Параметры и их обоснование

| Параметр | Значение | Обоснование |
|---|---|---|
| Источник данных | BingX, фьючерсный рынок | Целевая биржа проекта |
| Окно расчёта β | 500 минутных свечей | ~8,3 часа: достаточно наблюдений для устойчивой оценки; окно скользящее — β пересчитывается при каждом старте, модель адаптируется к текущему рынку |
| Интервал свечей | 1 минута | Совпадает с рабочим интервалом детектора |
| Окно детектора | 60 минут | Требование задания |
| Порог сигнала | ±1% | Требование задания |
| Доходность | (close_t − close_{t−1}) / close_{t−1} | Простая процентная доходность за минуту |

Фактические значения β на живых данных BingX: **1.25–1.48** ( ETH систематически
движется сильнее BTC — типичное поведение альткоина).

### Выравнивание по времени

Доходности ETH и BTC попарно совпадают по времени: доходность ETH за минуту N
сравнивается с доходностью BTC за ту же минуту. Свечи без пары исключаются —
иначе оценка β теряет смысл.

## Алгоритмическая сложность

Скользящее окно 60 минут обновляется за **O(1)**: хранится сумма окна,
при закрытии минуты к сумме прибавляется новое собственное движение и
вычитается выпавшее (deque с фиксированной длиной). Пересчёта всего окна
на каждой минуте нет. Расчёт β — один линейный проход по выборке (O(n),
n = 500, выполняется один раз при старте).

## Архитектура

    analyser/
      market_data.py     — MarketDataStream: WebSocket BingX (wss://open-api-ws.bingx.com/market),
                           подписки ETH-USDT и BTC-USDT, gzip-распаковка, Ping/Pong,
                           автопереподключение при обрывах
      historical_data.py — история минутных свечей через CCXT (ETH/USDT:USDT, BTC/USDT:USDT),
                           расчёт доходностей, выравнивание по времени
      beta_model.py      — BetaModel: fit() — оценка β = Cov/Var, own_move() — выделение
                           собственного движения
      detector.py        — OwnMovementDetector: скользящее окно 60 минут с O(1)-обновлением,
                           порог ±1%, формирование сигнала
    main.py              — сборка: при старте считает β по истории, затем в реальном времени
                           следит за рынком и печатает сигналы в консоль

Модули связаны через callback: поток данных не знает про анализ, анализ не знает
про WebSocket. Модули тестируются и заменяются независимо (например, на будущем
Telegram-боте с подпиской на сигналы).

## Установка и запуск

### Вариант 1: Docker (рекомендуется)

Требуется Docker / Docker Desktop.

    docker compose up --build -d     # сборка и запуск в фоне
    docker compose logs -f           # смотреть логи (сигналы появляются здесь)
    docker compose down              # остановка

Контейнер настроен на `restart: unless-stopped` — программа работает постоянно
и самостоятельно поднимается после сбоев и перезагрузок.

### Вариант 2: локально

Требуется Python 3.11.

    python -m venv venv
    .\venv\Scripts\activate          # Windows (Linux/macOS: source venv/bin/activate)
    pip install -r requirements.txt
    python main.py

Остановка: Ctrl+C.

## Тесты

    pytest --cov=analyser --cov-report=term-missing

Покрытие пакета `analyser` — **79%** (порог задания — 75%). Юнит-тесты покрывают
математику β, окно детектора, распаковку сообщений и выравнивание историй; живой
WebSocket-цикл проверяется интеграционным прогоном `main.py`.
