# PLAN.md — статус дипломного проекта ТА7

## Проект
**«Анализ собственных движений цены фьючерса ETHUSDT»** (Skyeng, дипломный проект ТА7).
Автор: Иван. Биржа: BingX. Репозиторий приватный: `UBaH-lab/eth-own-movement-analyser`.

## Суть методики (Часть 1 задания)
Собственное движение ETH = реальное движение ETH − β × движение BTC,
где β = Cov(ETH, BTC) / Var(BTC) по минутным доходностям (500 свечей истории).
Актуальная β ≈ 1.25 (ETH в среднем движется в 1.25 раза сильнее BTC).
История тянется через CCXT (`ETH/USDT:USDT`), живой поток — свой WebSocket
`wss://open-api-ws.bingx.com/market` (gzip, Ping/Pong, автопереподключение).

## Часть 2 задания (реализация)
- Раз в минуту: последние цены ETH и BTC → минутные доходности →
  собственное движение ETH (через β).
- Скользящее окно 60 минут, сумма окна обновляется за O(1)
  (deque: добавил новое, вычел выпавшее — без пересчёта всего окна).
- |сумма собственных движений| ≥ 1% → сообщение в консоль.
- Программа работает постоянно (автопереподключение WebSocket).

## Структура
